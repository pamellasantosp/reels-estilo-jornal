# reels-estilo-jornal

**Criado por Pâmella Santos** · [@pamellasantosp](https://instagram.com/pamellasantosp)

Skill do Claude Code que edita Reels no estilo jornal/colagem: papel bege, tarjas recortadas, fotos P&B em faixas, números gigantes, documento com marca-texto, tela dividida e rabiscos vermelhos.

## Instalar (Mac)
1. Copie esta pasta para `~/.claude/skills/reels-estilo-jornal`:
   `git clone <este repo> ~/.claude/skills/reels-estilo-jornal`
2. Rode `~/.claude/skills/reels-estilo-jornal/instalar.sh`. Ele instala ffmpeg, whisper e Python e baixa o modelo de transcrição.
3. No Claude Code, peça: "edita esse vídeo no estilo jornal" e mande o bruto.

O passo a passo completo e as regras de direção de arte estão em `SKILL.md`. O exemplo aprovado (caso Safra) está em `exemplo/`.

Fontes: Anton, Montserrat, Playfair Display e Libre Baskerville, todas com licença OFL. Fotos do exemplo: Wikimedia Commons (domínio público/CC).
